# Professional Calculator Web App

A responsive calculator application built as a frontend internship project using HTML, CSS, and JavaScript. It features a polished dark UI, keyboard support, arithmetic operations, decimal handling, percentage logic, and clean user interactions.

## Features

- Arithmetic operations: addition, subtraction, multiplication, and division
- Percentage calculations
- Decimal inputs and validation
- Clear and delete controls
- Real-time expression and result updates
- Keyboard support for desktop users
- Responsive design for mobile, tablet, and desktop screens
- Error handling for invalid expressions and division by zero
- Modern glass-inspired dark theme and subtle animations

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — app structure and calculator layout
- `style.css` — responsive styling, theme, and interactions
- `script.js` — calculator logic and keyboard handling
- `README.md` — project overview and usage instructions

## How to Run

1. Open the project folder in a browser.
2. Double-click `index.html` or serve the folder with a local web server.
3. Start using the calculator immediately.

Example local server command:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
